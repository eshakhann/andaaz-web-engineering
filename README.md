## About

ANDAAZ is a modern fashion e-commerce frontend developed as a Web Engineering project. It provides an elegant platform for exploring fashion collections and products, built using HTML5, CSS3, and JavaScript.

## Features

- Responsive website design
- Fashion categories and featured collections
- Interactive navigation
- Order form
- Light/Dark mode
- JavaScript interactions

## Technologies

- HTML5
- CSS3
- JavaScript

## 🚀 How to Run the Project

**Live Demo:** [Visit ANDAAZ Website](https://eshakhann.github.io/andaaz-web-engineering/)

To run locally:

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser.

*For the best experience, use Google Chrome or Mozilla Firefox.*
